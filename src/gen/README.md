# Generated code

Everything in this directory apart from this file is produced by `task contract` from the vendored
contract at the tag in [`CONTRACT`](../../CONTRACT). It is committed so a clean checkout builds
without `protoc`, and so a contract bump shows up as a reviewable diff — see
[decision 0002](../../docs/decisions/0002-commit-the-generated-typescript.md).

It is never hand-edited. A change here that did not come from `task contract` is a mistake rather
than a fix.
